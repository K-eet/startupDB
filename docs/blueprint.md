# **App Name**: StartupDB

## Core Features:

- Startup Directory: Browse a comprehensive directory of startups, filterable by industry, stage, and location.
- VC Directory: Explore a detailed directory of venture capital firms, with information on investment focus and contact details.
- Mobile-First Design: Optimized user interface for seamless mobile browsing experience.
- Intelligent Search: AI-powered search functionality to quickly find relevant startups and VCs based on keywords, using a tool to match criteria based on unstructured information.

## Style Guidelines:

- Emergent over prescribed aesthetics.
- Expose state and inner workings.
- Dense, not sparse.
- Explicit is better than implicit.
- Engineered for human vision and perception.
- Regiment functionalism.
- Performance is design.
- Verbosity over opacity.
- Ignore design trends. Timeless and unfashionable.
- Flat, not hierarchical.
- Diametrically opposite of minimalism, as complex as it needs to be.
- Driven by objective reasoning and common sense.
- Don't infantilize users.
- Use mono font
